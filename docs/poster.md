## 2. 背景与意义

- 传统安防依赖云端或服务器：延迟高、功耗大、隐私风险高。
- 边缘端纯软件方案：ARM CPU 很快被图像预处理占满，难以实时。
- 本作品将计算密集型预处理下沉到 FPGA，ARM 只做业务判断，实现低延迟、低功耗、可本地部署。
- 适用于仓库、机房、变电站、工业园区等周界安防场景。

## 4. 系统架构

**PL + PS 协同架构**

```text
USB 摄像头 (320×240)
        │
        ▼
┌──────────────────────────────┐
│  ARM PS (Python/OpenCV)      │
│  采集 / 打包 0x00RRGGBB      │
│  AXI DMA 下发 / 回读          │
│  跟踪 / 越线 / Web / 报警     │
└──────────┬───────────────────┘
           │ AXI-Lite / AXI-Stream
           ▼
┌──────────────────────────────┐
│  FPGA PL                     │
│  rgb2gray → frame_diff       │
│  → threshold → morphology    │
│  （交付版形态学由 PL 输出掩码）│
└──────────────────────────────┘
```

**要点**：
- PL：计算密集型流水线，每像素 II=1。
- PS：目标跟踪、越线计数、Web 配置、报警联动。
- AXI DMA 高速数据搬运；MMIO 直接访问寄存器，稳定绕过 hwh 兼容问题。

## 6. 技术创新点

1. **完整帧差法链路上 FPGA**
   将 rgb2gray、frame_diff、threshold、morphology 用 HLS 实现为 AXI-Stream IP，并在低成本 Zynq-7020 上跑通。

2. **形态学瓶颈搬上 PL（探索版）**
   级联 7×7 闭运算 + 3×3 开运算，验证阶段 FPS 提升至 138.07；交付版保留形态学掩码输出以平衡稳定性。

3. **MMIO 直接寄存器访问**
   针对 Vivado/PYNQ hwh 解析兼容问题，采用直接 MMIO 访问 AXI-Lite，工程更稳定。

4. **PL/PS 协同 + 完整业务功能**
   不止做预处理，还实现了跟踪、越线、Web 配置、蜂鸣器联动的完整边缘智能闭环。

## 7. 性能指标

**PYNQ-Z2 实测性能**

| 指标 | OpenCV 纯软件 | 本仓库交付版 | 形态学全上 PL（参考数据） |
|---|---:|---:|---:|
| FPS | 48.40 | 50.18 | 138.07 |
| 相对加速比 | 1.00× | 1.04× | 2.85× |
| 端到端延迟 | ~20 ms | ~20 ms | 7.20 ms |
| 单核 CPU | 99.98% | 96.25% | 93.71% |
| 效果一致率 | - | > 99.99% | - |

> 参考数据说明：138.07 FPS 来自“形态学全上 PL”探索版本，相关 bitstream 工程文件未包含在本仓库交付包中，仅作为性能潜力参考。交付版实测数据见 [`hardware/reports/runtime_benchmark_report.md`](../hardware/reports/runtime_benchmark_report.md)。

## 9. 总结与展望

- 本作品以 PYNQ-Z2 为核心，验证了“FPGA 预处理 + ARM 业务逻辑”在边缘入侵检测中的有效性。
- 交付版在保证功能等价的前提下，将 ARM 单核 CPU 占用从 99.98% 降至 96.25%，并为后续形态学全上 PL 留下 2.85× 性能空间。
- 后续可扩展：多警戒区、继电器联动、PL 连通域/bbox 输出、HDMI 直出。
