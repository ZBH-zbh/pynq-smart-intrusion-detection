# 本地运动检测基准报告

> 本报告只验证基准流程和指标计算，不代表 PYNQ PL 性能结果。

## 配置

- 输入：synthetic
- 分辨率：320×240
- 预热帧：20
- 测量帧：200
- 重复轮次：3
- 每轮最短性能计时：1.0 秒（完整循环 200 帧输入，效果指标只取首轮序列）
- OpenCV 线程数：16

## 性能

| 后端 | 平均 FPS | FPS 标准差 | P50 延迟/ms | P95 延迟/ms | 进程 CPU/单核口径 | 进程 CPU/总容量口径 | 系统 CPU |
|---|---:|---:|---:|---:|---:|---:|---:|
| OpenCV 标准灰度 | 2557.68 | 426.43 | 0.380 | 0.576 | 99.93% | 6.25% | 24.98% |
| HLS 整数灰度参考 | 789.70 | 67.68 | 1.255 | 1.710 | 98.00% | 6.12% | 28.51% |

## 一致性

| 指标 | 结果 |
|---|---:|
| 掩码像素一致率 | 0.999975 |
| 掩码平均 IoU | 0.998298 |
| 目标数量一致率 | 1.000000 |
| bbox 平均匹配 IoU | 1.000000 |
| 报警一致率 | 1.000000 |

## 解释

两个后端都在 Windows CPU 上运行。它们只在灰度转换方式上不同：一个使用 OpenCV `cvtColor`，另一个使用当前 HLS 的整数权重公式。正式 PL vs OpenCV 结果必须在 PYNQ-Z2 上、使用同一输入重新采集。
