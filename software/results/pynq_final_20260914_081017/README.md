# 最终 PYNQ 正式结果

测试日期：2026-09-14  
平台：PYNQ-Z2，PYNQ 3.0.1，Python 3.10.4，OpenCV 4.5.4  
口径：320×240 确定性合成帧，预热 20 帧，200 帧 × 3 轮，OpenCV 单线程，无采集、显示和 JPEG 开销。

## 核心结果

| 指标 | OpenCV 纯软件 | 优化 PL |
|---|---:|---:|
| 平均 FPS | 48.40 | 50.18 |
| P50 延迟 | 20.585 ms | 19.874 ms |
| P95 延迟 | 20.770 ms | 20.019 ms |
| 进程 CPU/单核口径 | 99.98% | 96.25% |
| 进程 CPU/总容量 | 49.99% | 48.13% |

PL 相对 OpenCV 为 1.0367×，即快 3.67%；单核 CPU 低 3.73 个百分点。

## 文件说明

- `benchmark_results.json`：完整参数、环境、逐轮和汇总数据。
- `benchmark_runs.csv`：6 次后端轮次的原始统计。
- `benchmark_report.md`：程序自动生成的简要报告。
- `profiles/`：50 us 与 100 us DMA 轮询实验的分阶段耗时数据。

比赛和答辩引用本目录数据。优化版约 3 分钟摄像头持续回归稳定，显示为 17.1±0.1 FPS；它包含 USB 摄像头、JPEG 和 Jupyter 页面刷新，不能与本目录的无显示核心吞吐直接比较。
